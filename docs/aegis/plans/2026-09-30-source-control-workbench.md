## Canonical interface
All old methods/routes/envelopes preserved. New operation names on createOperations and SourceControlService:
- branches({root,signal}) -> {current: string|null, head:string|null, local:[{name,ref,hash,current,upstream:string|null,upstreamTarget:{remote,branch}|null}], remote:[{name,ref,hash,remote,branch}], remotes:[{name}]}. Remote entries exclude symbolic HEAD refs. Do not expose credential-bearing URLs. `upstream` is a display name only; `upstreamTarget` is the canonical structured target derived from %(upstream:remotename)+%(upstream:remoteref) and is non-null even when the local tracking ref is missing, null for a `.` local upstream. One shared predicate serves branches() and target().
- graph({root,skip=0,signal}) -> {commits:[{hash,short,parents:string[],author,date,subject,refs:[{name,kind}]}], hasMore:boolean}. kind local|remote|tag|head. Walks local branches, remote-tracking branches, tags and HEAD — the refs this view decorates — never the whole ref namespace, so `refs/replace/*` (phantom row) and `refs/stash` (leaked stashed work) stay out; topological order, bounded pagination. Preserve old log operation/API for compatibility, not as a new-client fallback.
- commitDetails({root,hash,signal}) -> {commit:{hash,short,parents,author,date,subject,message}, files:[{path,status,oldPath:string|null}]}. Validated exact full object ID only; changes versus first parent, root commit versus empty tree. Paths are repository-relative historic paths, never read from current working tree.
- commitDiff({root,hash,path,signal}) -> existing parsed diff shape; historic changes are read-only, no hunk actions; requested path must belong to that commit's files. Support deleted/renamed and root files; diff is bounded like existing diff.
- switchBranch({root,branch,remoteBranch?,signal}) -> {branch}. Existing local branch by name, OR remoteBranch exact name from branches.remote with requested local branch name, then create tracking branch. Require completely clean status. No detach/force/discard.
- createBranch({root,branch,signal}) -> {branch}; create and switch at current HEAD, require clean tree. No unborn/detached implicit assumptions.
- fetch({root,remote,signal}) -> {remote}; configured remote name only, no recursive submodules or automatic network in reads.
- pull({root,sourceBranch,remote?,branch?,signal}) -> {remote,branch}; sourceBranch is the required UI-captured source and must still equal the current local branch at execution. Target defaults from that source's upstream if omitted. Require clean tree; only ff-only, no rebase/auto-stash/recursive submodules. Missing upstream/target yields explicit refusal. Explicit branch targets validated, never raw refspec/URL.
- push({root,sourceBranch,remote?,branch?,setUpstream=false,signal}) -> {remote,branch}; sourceBranch is required, captured when the UI dialog opens, checked against current inside queue execution, and used as the explicit refspec source. Target defaults from that source's upstream. Only current local branch pushed. No upstream requires explicit remote/branch and setUpstream true. Ordinary non-forced push; no tags/mirror/delete/follow-tags; remote destination validated and argv-only. Upstream confirmation is a UI dialog, setUpstream boolean server-validated.

New GET routes: /branches, /graph?skip=, /commit-details?hash=, /commit-diff?hash=&path=. New POST routes: /switch-branch {branch,remoteBranch?}, /create-branch {branch}, /fetch {remote}, /pull {sourceBranch,remote?,branch?}, /push {sourceBranch,remote?,branch?,setUpstream?}. Every route includes existing sessionId/repo selector; POST always read:false; GET read:true. Stable JSON envelope remains. No expansion of agent-facing ACTIONS.

Git layer: validate names with Git ref validation plus reject option/refspec syntax; resolve branch/remotes from repository, never run caller shell text. Clear prompting, bound output/time/abort, use host Git/SSH credentials without sending secrets to browser. Redact credential-bearing URL/error output. Fetch/pull/push select configured names only. Do not enable unsafe external protocols. Reads are enforced local, not merely intended: non-transport calls run with protocol.allow=never and GIT_NO_LAZY_FETCH=1 so a partial (promisor) clone cannot fetch during a read, and immutable historical reads additionally run with replacement objects disabled and signature display off. Pull/push must override dangerous user config (pull.rebase, pull.ff, autostash, push.default/mirror/followTags/force refspec). Ref validation must support Unicode and slash names without treating them as paths.
Service: resolve canonical root once per call and enqueue EVERY mutation (old stage/unstage/discard/hunks/commit AND new branch/fetch/pull/push) in same per-root queue; failed/cancelled task cannot poison later work. Path guards inside serialized mutation. Reads remain reads. Context selector unchanged. commitDiff performs historic Git membership checks, not filesystem containment against deleted paths.
